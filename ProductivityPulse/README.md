# Pomodoro Timer App

A modern, React-based Pomodoro timer application to help boost productivity and maintain focus.

## Features

- 🕒 Three timer modes:
  - Pomodoro (25/5 minutes)
  - Deep Work (45/15 minutes)
  - Sprint (15/3 minutes)
- ⏯️ Start, pause, and reset functionality
- 🔄 Automatic work/break phase switching
- 🔊 Audio notifications when phases change
- ⚡ Quick time adjustment controls
- 💅 Clean, modern UI with smooth animations

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- shadcn/ui components
- Zustand for state management
- Framer Motion for animations

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/LiquidAzir/Pomodoro-Timer-App.git
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

## Usage

1. Select your preferred timer mode (Pomodoro, Deep Work, or Sprint)
2. Click the Start button to begin your focus session
3. Use the time adjustment buttons if needed
4. The timer will automatically switch between work and break phases
5. Audio notifications will play when phases change
